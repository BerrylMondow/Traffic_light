# 🚦  Traffic Light Simulator

Simulasi lampu lalu lintas sederhana yang dibuat menggunakan **HTML, CSS, dan JavaScript**. Proyek ini menampilkan interaksi dinamis di mana pengguna dapat mengontrol nyala dan matinya lampu melalui tombol navigasi.

---

## ✨ Fitur Utama

- 🔴 **Red Light**: Menyalakan lampu merah.
- 🟡 **Yellow Light**: Menyalakan lampu kuning.
- 🟢 **Green Light**: Menyalakan lampu hijau.
- 🚦 **All Lights**: Menyalakan/mematikan semua lampu secara bersamaan.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman web dan elemen tombol/lampu.
- **CSS3**: Penataan layout, styling warna dasar, dan status aktif lampu.
- **JavaScript (ES6+)**: Logika manipulasi DOM dan penanganan event listener (`click`).

---

## 📁 Struktur File

- **index.html**        # Struktur markup utama
- **style.css**         # Styling UI dan warna lampu
- **script.js**        # Logika interaksi JavaScript
